# M13 — Frontend móvil

Estado: completado.

## Resultado

- La interfaz final sustituye la consola M10 por acceso privado, chat,
  historial, memorias, ajustes y navegación inferior adaptada a safe areas.
- El arranque abre SQLite y pinta conversaciones/memorias/mensajes cacheados
  antes de intentar sincronizar con MySQL.
- El estado Svelte está normalizado por ID; los mensajes se actualizan por
  conversación y los deltas SSE se agrupan en un único estado de respuesta,
  sin rerenderizar el historial completo.
- Un mensaje optimista se escribe primero en SQLite. Solo se añade al outbox si
  no hay red, la conversación aún no está sincronizada o el stream falla antes
  de emitir `start`; el mismo `clientOperationId` conserva la idempotencia.
- Memorias se crean y activan/pausan offline con el mismo patrón entidad +
  operación. El token nunca entra en Svelte: Keystore/Keychain permanece detrás
  de Rust.
- La aplicación reintenta al recuperar red o visibilidad, permite cancelar una
  generación, conserva caché tras reinicio y no ejecuta SQL ni HTTP desde el
  WebView.
