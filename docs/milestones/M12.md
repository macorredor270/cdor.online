# M12 — Frontend web

Estado: completado.

## Resultado

- La portada pública reemplaza el esqueleto técnico y ofrece acceso privado,
  recuperación y cambio de contraseña mediante Better Auth.
- El área autenticada aplica guard server-side y contiene navegación adaptable,
  historial paginado, creación de conversaciones, chat, memorias, uso, ajustes
  locales y gestión de dispositivos.
- El chat consume `POST /api/v1/chat/stream` mediante `fetch`, procesa los cinco
  eventos CDOR incrementalmente y permite cancelar la generación.
- Los deltas actualizan únicamente la respuesta activa. Los mensajes históricos
  usan `content-visibility` y paginación de 50 elementos para evitar un
  rerender global o un DOM inicial ilimitado.
- El Markdown se convierte a nodos Svelte tipados. No existe `{@html}`; HTML
  recibido se muestra como texto y solo se crean enlaces `http` o `https` con
  `noopener noreferrer`.
- Memorias permite crear, activar, desactivar y eliminar contra MySQL mediante
  la API existente.
- Cuenta permite vincular el navegador, listar y revocar dispositivos. Uso
  muestra un resumen real de 30 días calculado en `usage_events`, aislado por
  propietario.
- Los ajustes de tema se etiquetan expresamente como locales. No se simula una
  sincronización mientras no exista una ruta pública estable de preferencias.
- Se añadieron privacidad, términos provisionales, `robots.txt`, sitemap,
  favicon y metadatos correctos de CDOR para sustituir la indexación histórica
  ajena al proyecto.
- El registro público continúa deshabilitado.

## Riesgos pendientes

- Privacidad y términos reflejan la arquitectura actual, pero son provisionales
  y requieren aprobación legal antes de abrir el registro.
- Las preferencias sincronizables existen en el contrato de sync, pero no
  cuentan aún con una ruta web dedicada; el tema se guarda solo en el navegador
  y se comunica así en la interfaz.
- El smoke E2E autenticado completo deberá repetirse en producción tras el
  despliegue. Las rutas, ownership y ciclos reales de auth/chat ya están
  cubiertos por las suites backend, auth, streaming y la prueba física M11.
- GitHub impidió arrancar el publicador de Hostinger por un problema de
  facturación o límite de gasto de la cuenta, no por un fallo del repositorio.

## Condición exacta de detención

M12 se cierra porque acceso, chat, historial, memorias, ajustes, cuenta, uso y
páginas legales están implementados sobre las APIs; el Markdown no admite HTML
ejecutable; teclado, landmarks y estados vivos están comprobados; la prueba de
1.000 mensajes y el presupuesto de bundle pasan; Lighthouse obtiene 100 en las
cuatro categorías.
