# M11 — Debug Android mediante ADB

Estado: completado.

## Resultado

- Todos los comandos ADB se dirigieron explícitamente al Xiaomi con serial
  `HQRSFUZXXOR4PN6L`; el Mi TV no fue seleccionado ni modificado.
- Los scripts USB y LAN fallan si falta el serial o si no coincide con el
  Xiaomi autorizado. Retiran solo sus propios forwards y nunca ejecutan
  `pm clear`, `uninstall` ni una limpieza global.
- HMR y la recompilación Rust funcionaron por USB. La variante LAN comprueba
  que la dirección indicada pertenece a una interfaz IPv4 local.
- Android resuelve `cdor.online` mediante la red activa del sistema y entrega
  las direcciones a `reqwest`, que conserva el hostname para validar TLS.
- La sesión Better Auth permanece en Android Keystore y sobrevivió a
  actualizaciones y reinicios de la aplicación.
- El ciclo offline → outbox → online convergió contra MySQL sin duplicar:
  cursor local 42 → 44, una operación enviada, dos cambios recibidos y cero
  operaciones pendientes. Una repetición produjo cero envíos y cero cambios.
- Se corrigió la reejecución idempotente de mensajes rechazados temporalmente
  porque aún no había llegado su conversación. MySQL confirmó ambas entidades
  con `sync_version=1`.
- Un stream NVIDIA real terminó con `stop`. Otra generación se canceló desde
  el Xiaomi y terminó con `STREAM_CANCELLED`, sin exponer la clave al WebView.
- La build release ARM64 se firmó solo para medición con el keystore debug
  local, verificó firmas APK v2/v3 y se instaló con `adb install -r`.
- El arranque en frío medido por Android fue de 926 ms. El APK firmado ocupa
  23.000.464 bytes.
- La medición en reposo dio 84.588 KiB de PSS y 264.072 KiB de RSS. No hubo
  entradas de la aplicación en el buffer de crashes.

## Riesgos pendientes

- `gfxinfo` solo capturó un frame detrás del keyguard; no se usa como evidencia
  de fluidez. La medición de scroll sostenido corresponde al frontend móvil de
  M13, con la interfaz final y el dispositivo desbloqueado por su propietario.
- MIUI bloquea algunas operaciones de red de la aplicación cuando permanece
  detrás del keyguard. Las pruebas de red deben mantener la aplicación visible;
  no se elimina ni se automatiza el PIN.
- La firma utilizada es exclusivamente de desarrollo. Firma, publicación e iOS
  pertenecen a M14.
- La regla temporal de MySQL remoto usada para comprobar la convergencia fue
  revocada; la lista final conserva únicamente el origen de Hostinger.

## Condición exacta de detención

M11 se cierra porque una build release está instalada y medida en el Xiaomi
exacto; autenticación, caché, reinicio, outbox, convergencia sin duplicados,
streaming y cancelación funcionan contra producción. El teléfono queda con
`stayon` desactivado y no se ha ejecutado ninguna limpieza destructiva.
