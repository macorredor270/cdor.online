# M5 — Autenticación

Estado: completado el 27 de julio de 2026.

## Resultado implementado

- Better Auth 1.6.25 con adaptador Drizzle MySQL y ULID en todos sus IDs.
- Registro gobernado por `AUTH_SIGN_UP_ENABLED`, deshabilitado por defecto.
- Verificación de correo obligatoria y recuperación con revocación de sesiones.
- Transporte SMTP reemplazable, timeouts y TLS 1.2 mínimo.
- Cookies `HttpOnly`, `SameSite=Lax` y `Secure` en producción.
- Bearer móvil con firma obligatoria.
- Validación de origen/CSRF explícitamente habilitada.
- Resolución de Better Auth hacia la abstracción `Principal`.
- Dispositivos vinculados a sesiones y revocación por usuario/dispositivo.
- Nueva migración `session.device_id` con índice de ownership.
- Workflow aislado para autenticación, sin secretos ni migraciones de
  producción.

## Validación externa

Resend quedó confirmado como proveedor reemplazable por decisión del 27 de
julio de 2026. Los cuatro grupos DNS solicitados se añadieron de forma aditiva
mediante la API oficial de Hostinger:

- DKIM `TXT resend._domainkey`;
- return path `MX send` con prioridad 10;
- SPF `TXT send`;
- DMARC `TXT _dmarc`.

Hostinger validó el lote antes de escribirlo y ambos nameservers autoritativos
respondieron después los cuatro valores exactos. La zona previa se guardó en
`backups/hostinger-dns-pre-resend-20260727.json`, fuera de Git y con permisos
`600`.

Las credenciales SMTP y `BETTER_AUTH_SECRET` están presentes en el `.env`
privado. El transporte completó la autenticación SMTPS, Resend aceptó tanto su
dirección sintética `delivered@resend.dev` como el destinatario real en Proton,
y el usuario confirmó la recepción. El comando ejecutado fue:

```bash
pnpm smoke:smtp -- destinatario@dominio
```

## Condición de detención

M5 no se considera terminado y M6 no comienza hasta que:

1. el transporte SMTP autentique;
2. el mensaje de prueba sea recibido;
3. el remitente y los enlaces usen el dominio correcto;
4. una prueba de aislamiento confirme que un usuario no accede a dispositivos
   de otro usuario.

Cumplida: el transporte autentica, el mensaje fue recibido con el remitente
`no-reply@cdor.online`, el registro público continúa deshabilitado y las pruebas
de ownership impiden acceder a dispositivos de otro usuario. M6 puede comenzar.
