# M1 — Contratos

Estado: completado el 27 de julio de 2026.

## Resultado

`@cdor/contracts` es la fuente única de los esquemas Zod y de los tipos
TypeScript inferidos para:

- convenciones comunes, sobres y errores;
- autenticación, sesión, perfil y dispositivos;
- conversaciones, mensajes, streaming y memorias;
- preferencias, pull/push de sincronización e idempotencia.

Las decisiones de wire format quedan documentadas en
[`../api.md`](../api.md). En particular:

- IDs ULID Crockford en mayúsculas;
- fechas ISO 8601 UTC con milisegundos;
- valores MySQL `BIGINT UNSIGNED` como cadenas decimales;
- objetos estrictos y errores con códigos estables;
- cinco eventos SSE propios de CDOR;
- mensajes sincronizados append-only desde el cliente;
- cursor caducado mediante `SYNC_CURSOR_INVALID`.

Platform y mobile importan tipos desde el paquete compartido. No se añadieron
interfaces paralelas ni lógica de frontend.

## Evidencia

Pasaron:

```bash
source scripts/env.sh
pnpm install --frozen-lockfile
pnpm --filter @cdor/contracts check
pnpm --filter @cdor/contracts test
pnpm check
pnpm test
pnpm build:platform
pnpm build:mobile
cargo check --locked --manifest-path apps/mobile/src-tauri/Cargo.toml
```

Resultado de tests de contratos:

```text
Test Files  4 passed (4)
Tests      17 passed (17)
```

También se creó una copia limpia del árbol y pasó:

```bash
pnpm install --frozen-lockfile --filter @cdor/platform...
pnpm build:platform
```

La instalación alcanzó únicamente `@cdor/platform` y `@cdor/contracts`; no creó
`apps/mobile/node_modules`.

## Riesgos pendientes

- Los tipos son portables por JSON, pero la representación equivalente en Rust
  no se implementará hasta M9.
- Los contratos fijan el protocolo, no la autorización ni la persistencia; los
  endpoints aún no existen.
- Cambiar un enum, límite o forma pública desde este punto requiere revisar
  compatibilidad y tests de web, móvil y backend.
- La contraseña MySQL mostrada durante la configuración debe rotarse antes de
  conectar cualquier entorno. No está almacenada en el repositorio.

## Condición de detención

La puerta de M1 está superada: contratos probados, importables por ambos
consumidores y sin ambigüedades pendientes de wire format. El trabajo se detiene
aquí; no se inicia validación (M2), MySQL (M3) ni backend.
