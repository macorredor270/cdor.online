# M6 — NVIDIA NIM

Estado: completado el 27 de julio de 2026.

## Resultado

- `AiProvider` desacopla catálogo y streaming del proveedor.
- `NvidiaNimProvider` valida respuestas, aplica timeout, propaga cancelación y
  normaliza deltas, uso y finalización.
- La allowlist impide exponer automáticamente el catálogo de NVIDIA.
- El constructor de prompt reserva salida, conserva los turnos recientes y
  selecciona memorias habilitadas por importancia y actualización, sin
  embeddings.
- El presupuesto usa una estimación conservadora y nunca recorta el mensaje
  actual de forma silenciosa.
- El proveedor simulado permite probar integraciones sin red.
- La suite comparativa fija pondera 50 % calidad, 30 % latencia y 20 % coste.
- El ganador exacto `meta/llama-3.1-8b-instruct` quedó en el `.env` privado.
- OpenRouter existe únicamente como alternativa experimental gratuita, con un
  guard que bloquea modelos de pago antes de realizar la petición.

## Evidencia

```text
pnpm test:ai

```

Las variables privadas permanecen exclusivamente en `.env`, que está ignorado
por Git y con permisos restringidos.

## Riesgos pendientes

- Los endpoints gratuitos pueden cambiar de catálogo, límites o disponibilidad.
- La métrica de coste NVIDIA es consumo relativo de tokens, no una tarifa
  monetaria publicada.
- OpenRouter gratuito no es apto como fallback transparente de producción.
- La suite fija es deliberadamente pequeña; debe versionarse si cambian las
  capacidades esperadas del producto.
